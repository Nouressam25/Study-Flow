# Study Flow 📚 – Web-Based Task Management System

**Study Flow** is a comprehensive task and course management web application designed to help students organize their academic workload, track deadlines, and improve productivity.

---

### ✨ Key Features
- **User Authentication:** Secure registration and login functionality for students.
- **Course Management:** Add, update, and manage academic courses efficiently.
- **Task Tracking (CRUD):** Create, read, update, and delete tasks associated with specific courses.
- **Status Updates & Progress:** Mark tasks as completed and filter pending vs. completed tasks.
- **Calendar & Dashboard View:** Visual overview of upcoming deadlines and course activities.

---

### 🛠️ Tech Stack
- **Backend:** Python, Flask, SQLAlchemy
- **Database:** SQLite / Relational Database
- **Frontend:** HTML5, CSS3, JavaScript
- **Architecture:** Model-View-Controller (MVC) pattern
